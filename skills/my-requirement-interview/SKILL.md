# my-requirement-interview

Ask short rounds (usually 2–3 linked decisions), concrete options and a recommendation with tradeoffs. Research requests remain discussion. Small explicit tasks need no interview. Record confirmed requirements; do not insert unapproved suggestions into scope/spec. If user says do it, implement the agreed scope without confirmation loops; ask only material missing details. See [feature workflow](references/feature.md) when preparing a feature plan.
