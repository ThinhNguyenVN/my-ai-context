# my-figma-ui

Read [UI workflow](references/ui.md). Confirm Figma access, frame, design context, screenshot and states before coding. Resolve MCP failure or propose an alternative, never guess silently. Map existing design system components/tokens; Hive only in projects already using it. Compare rendered UI when tools allow; state platforms checked and gaps. Creative design skills are for exploratory work, not redesigning approved Figma.
