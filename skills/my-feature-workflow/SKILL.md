# my-feature-workflow

Follow [feature workflow](references/feature.md). Read similar features and repo instructions before proposing patterns. Existing OpenSpec: use its workflow. No OpenSpec: ask before introducing it. Approved scope and existing conventions guide implementation; do not apply generic best practices as architectural mandates. This workflow decides scope and when coding starts. It does not replace repository conventions and it does not review the result.
